# 可复制的购票请求模板

把方括号中的内容替换为自己的需求。不要把密码、完整身份证号、短信验证码或支付凭证填进模板。使用已保存的观演人名称或其他你能辨认的代称即可；正式观演人信息在大麦官方页面核对。

## 模板一：第一次使用，只验证安装

```text
请使用 $damai-ticket-assistant，只做安装验证。
请确认你能找到并读取这个 Skill，说明购票前需要准备哪些信息，
并检查当前环境是否有可用、已授权的浏览器控制工具。

不要登录账号，不要创建订单，不要支付。
```

## 模板二：只做购票准备

```text
请使用 $damai-ticket-assistant 帮我准备购票。

活动官方链接：[https:// 开头的大麦官方活动链接]
活动名称：[名称]
城市、场馆：[城市、场馆]
场次：[年月日、开场时间；默认北京时间]
数量：[张数]
票档第一选择：[票档]
票档第二选择：[票档 / 无]
座位要求：[是否必须连座、是否接受视线受限座位等]
无障碍需求：[具体需求 / 无]
每张票价上限：[人民币金额]
含所有必要费用的总预算：[人民币金额]
允许换场次：[不允许 / 具体场次]
允许减少数量：[不允许 / 最少张数]
观演人：[我会在官方页面确认的已保存观演人]
取票方式偏好：[电子票 / 官方现场领取 / 配送 / 接受平台提供的方式]
计划停止时间：[年月日 时分，北京时间]

本次只查询和准备，不创建订单，不支付。
请列出缺失信息和你从官方页面确认的规则。
需要登录或填写身份信息时，我会在官方页面自己完成。
```

## 模板三：只允许创建订单，付款由我处理

创建订单也可能占用库存或产生限时付款义务。确认准备好后再使用。

```text
请使用 $damai-ticket-assistant，按以下条件购买：

活动官方链接：[大麦官方活动链接]
唯一指定场次：[活动、城市、年月日、开场时间]
数量：[张数]
票档优先顺序：[按顺序列出可接受的票档]
座位要求：[具体要求]
观演人：[我已在官方页面确认的已保存观演人]
总价上限：[人民币金额] 元，含手续费、配送费等全部必要费用
允许的备选方案：[无 / 明确列出]
授权截止时间：[年月日 时分，北京时间]

我授权你在以上条件全部满足时创建最多 1 个订单。
订单创建后请报告官方订单号、实际总价及付款截止时间，然后停止；不要发起支付。
如有匹配的现有待支付订单，先检查该订单，不要新建另一单。
如果提交结果不确定，先核对订单记录，不要重试提交。
```

## 模板四：授权在限定范围内购买并继续支付

本模板包含实际购票授权。请填清预算、场次、数量和截止时间后再发送。

```text
请使用 $damai-ticket-assistant 帮我完成这次购票。

活动官方链接：[大麦官方活动链接]
指定场次：[活动、城市、年月日、开场时间]
数量：[张数]
票档优先顺序：[按顺序列出]
必须满足的座位要求：[连座、区域等；无则填无]
观演人：[我已在官方页面确认的已保存观演人]
每张票价上限：[人民币金额] 元
订单总价上限：[人民币金额] 元，含全部必要费用
允许的其他场次：[无 / 列出具体场次和优先顺序]
允许减少数量：[不允许 / 具体范围]
取票方式：[偏好；配送地址在官方页面填写]
支付方式偏好：[平台实际提供的支付方式]
授权截止时间：[年月日 时分，北京时间]

我授权你在以上限制内创建订单并继续到支付，最多购买成功 1 单。
我会留在场，亲自完成官方登录、验证码、扫码和支付验证。
需要本人验证时请告诉我当前页面和剩余期限，让我在官方界面完成。
超出预算或改变未授权条件时，先展示具体订单变化并等我确认。
如果订单或支付结果不明确，只检查已有记录，不重复下单或付款。
完成后请区分已支付待出票和已出票，并说明官方的取票或入场方式。
```

## 模板五：检查已有订单或异常支付

```text
请使用 $damai-ticket-assistant，只检查已有交易。

活动和场次：[活动、日期、时间]
订单标识：[官方订单号（如已知）或在订单列表中可辨认的信息]
刚才发生的情况：[例如：提交后白屏 / 扫码后订单未更新 / 已支付但未出票]

不要创建新订单，不要再次支付，也不要自动取消订单。
先在官方界面核对已有订单和支付状态。
请说明已经确认的事实、仍不确定的部分、当前需要我做的事及已知期限。
不要仅凭页面跳转、提示参数或超时就判断交易结果。
```

## 模板六：停止后续操作

```text
请停止这次购票的后续提交和支付操作。
报告是否已有订单、是否存在待确认的支付、以及平台显示的剩余期限。
不要自动取消订单或申请退款。
如需取消，请先给我当前订单状态和适用规则，等我另行授权。
```

有订单不等于已支付，已支付也不等于已出票。若状态不明确，应先查清已有交易，再决定下一步。
